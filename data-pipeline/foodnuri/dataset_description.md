# crop_data.json — 데이터셋 설명

## 개요

농림축산식품부 운영 포털 **농식품우리누리(foodnuri.go.kr)**의 "제철농식품" 코너에서 수집한 국내 농산물 지식 데이터셋입니다.  
총 **182종** 작물의 제철 시기·영양·효능·조리법·보관법·구입 요령 등을 구조화된 JSON으로 저장합니다.

---

## 수집 출처

| 항목 | 내용 |
|------|------|
| 원본 사이트 | https://www.foodnuri.go.kr |
| 대상 메뉴 | 제철농식품 (`/portal/bbs/B0000283/list.do`) |
| 수집 일시 | 2026-06-04 |
| 수집 도구 | Python 3.11 — `requests`, `beautifulsoup4` |

---

## 수집 방법

### 1단계 — 월별 목록 페이지 순회 (`crawl_foodnuri2.py`)

- 1월~12월 각 월별 목록 페이지를 요청 (`selectMonth` 파라미터)
- 각 월에 여러 페이지가 있을 경우 `pageIndex`를 증가시키며 다음 페이지 링크가 없을 때까지 반복
- 목록에서 각 작물의 상세 페이지 URL(`div.boxs a.name`)을 수집

### 2단계 — 상세 페이지 파싱

- 각 작물 상세 페이지(`div.view.type3`)의 `dl/dt/dd` 구조를 파싱
- 영양(`영양`) 필드는 내부 `<table>` 태그와 불필요 태그를 제거한 뒤 텍스트만 추출
- 페이지마다 HTML 구조가 달라 아래 세 가지 케이스를 순서대로 적용:
  1. `<p>` 태그로 분리된 경우 → `<p>` 단위 파싱
  2. `-` 구분자로 이어진 한 덩어리인 경우 → `-` 기준 분리
  3. 나머지 → 줄 단위 파싱

### 3단계 — 텍스트 정제

- 각 텍스트 행 앞의 `-` 기호 제거
- 마침표로 끝나지 않는 문장에 마침표 추가
- 1글자 이하 잔여 토큰 제거
- 분류(`분류`) 필드가 `"농산물 > 채소류"` 형식인 경우 `>` 뒤 값만 사용

### 4단계 — 중복 제거

- 동일 작물명이 여러 월에 등재된 경우, **먼저 등장한 월의 데이터만 유지**
- `crop_name` 기준 `set`으로 전역 중복 체크

## 필드 정의

| 필드명 | 타입 | 설명 |
|--------|------|------|
| `crop_name` | string | 작물 이름 (예: `"솔부추"`) |
| `category` | string | 농산물 분류 (예: `"채소류"`, `"과일류"`) |
| `season_month` | int | 대표 제철 월 (수집 시 사용한 `selectMonth` 값, 1~12) |
| `harvest_months` | int[] | 출하 가능 월 목록 (예: `[1, 2, 3]`) |
| `production_period` | string | 생산 시기 텍스트 (예: `"12~1월"`) |
| `origin_region` | string | 주요 산지 (예: `"경기도 양주, 연천"`) |
| `cooking_method` | string | 조리법 설명 |
| `storage_method` | string | 손질·보관법 설명 |
| `nutrition_brief` | string | 주요 영양 성분 요약 (표 데이터 제외, 설명 텍스트만) |
| `effect_brief` | string | 건강 효능 요약 |
| `purchase_tip` | string | 구입 요령 |
| `source_url` | string | 원본 상세 페이지 URL |
| `crawled_at` | string (ISO 8601) | 수집 시각 (UTC) |

## 주의사항

- **저작권**: 원본 데이터의 저작권은 농림축산식품부·농식품우리누리에 귀속됩니다. 비상업적·연구 목적으로만 사용하십시오.
- **카테고리 비정규화**: 원본 사이트의 분류 표기가 페이지별로 상이합니다. 필요 시 `category` 필드를 별도로 정규화하여 사용하세요.
- **영양 수치 미포함**: `nutrition_brief`는 영양 성분 수치 표를 제외한 설명 텍스트만 담습니다. 정량 데이터가 필요하다면 원본 URL에서 직접 확인하세요.
- **season_month vs harvest_months**: `season_month`는 수집 시 필터로 사용한 월(대표 제철)이고, `harvest_months`는 실제 출하 가능한 전체 월 목록입니다. 제철 범위 조회에는 `harvest_months`를 사용하세요.
