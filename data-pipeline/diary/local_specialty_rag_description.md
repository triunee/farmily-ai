## 필드 설명

| 필드 | 설명 |
|---|---|
| `crop_name` | 정규화된 작물명 (`selected_farmers_custom.json`의 `crop_name`과 동일 기준) |
| `local_name` | 지역 브랜드명 (예: "논산딸기", "고성 참다래") |
| `region` | 해당 특산물의 주산지 행정구역 |
| `source_url` | 원본 출처 URL |
| `source` | 데이터 출처명 (`"지역N문화"` 고정) |
| `content` | 특산물 역사·재배 현황·품종·산업 특구 등 서술형 본문 |

## 선별 기준

`selected_farmers_custom.json`의 최종 선별 농가 중 **지역 특산물로 공인된 작물**에 한해 수집했다.  
배(나주배)는 공식 특산물 지정 지역과 선별 농가 주소(전라남도 나주시)가 일치하지 않아 제외했다.

## 활용 방식

영농일지 기반 AI 콘텐츠 생성 시 해당 작물·지역 조합의 `content`를 RAG 컨텍스트로 주입한다.  
예: 충남 논산 딸기 농가의 일지 → `논산딸기` 본문을 프롬프트에 포함 → 산지 스토리텔링 콘텐츠 생성
